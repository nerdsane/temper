# temper code review

Read the repository [REVIEW.md](../../REVIEW.md) and its linked Stack contract. They own the criteria and scope. Read the change and independently exercise its intended behavior using the relevant repository checks.

Return concrete findings with reproduction evidence, file/line, impact and tests run. Identify limitations. Review only the accepted change and defects it introduces or worsens; do not assess the entire repository or demand unrelated improvements. Review is advisory; do not write approval markers or start other reviewers.
