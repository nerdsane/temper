# Styled artifacts

## Design output

Any styled artifact (HTML reports, dashboards, pages) follows the Katagami way:

- Use the linked design language's DESIGN.md tokens exactly. Standing default: [Galley](https://katagami.ai/language/en-019f2e78-8711-7072-b72d-200b095d9a51). The linked language always wins.
- Bright and clean; <=3 accents; no grey borders; no emoji on buttons; light default; body 17px+; high contrast; responsive; titles never stuck to container tops.
- Diagrams are real architecture diagrams (inline SVG, explainer under each), not tables or charts.
- One canonical living HTML deliverable; preserve the previous version before restyling; verify the rendered page yourself before handover.
